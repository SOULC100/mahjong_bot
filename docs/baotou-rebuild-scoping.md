# 设计稿（scoping）：爆头「到达率」的结构重建

> 状态：**只做范围界定与预注册判据，不动策略代码**（2026-09-23）。
> 上游证据：`docs/opp-baotou-teardown.md`（对手逆向）、`docs/eval-rounds.md` §27~§29（四轮证否）、
> `docs/plan-commit-design.md`（R21，已被本轮的零风险探针判死）、`docs/action-plan-2026-09-23.md` §3-R3/R6。
> 本文要回答的问题只有一个：**要把爆头到达率从 0.94% 往对手的 3.05% 推，剩下唯一可能的路是什么、
> 它最小的一步长什么样、以及在哪一步就该停。**

---

## 0. 一句话背景

番型缺口是**唯一统计显著的系统性缺陷**（爆头率 5.4% vs 22.9%，z=−8.03，Fisher p=1.8e−18），
同位置折分 **+0.634 分/局**——**补上它净分就从 −0.466 变成 +0.168**。
缺口 100% 在「**到达**」：爆头听牌态 我 0.94% vs 对手 3.05%（3.2×），而听牌→胡转化 83% vs 79% 相同。

## 1. 不可再走的路（全部有实测，含本轮新增三条探针）

| 路线 | 结论 | 证据 |
|---|---|---|
| 出牌层「保白 / 换主项 / bonus」（R20 四轮） | 全负或惰性 | `bao_plan` **−1.105**（z=−4.82，场均番反降 0.028）；`bao_w` 0 翻转；`baotou_slack+max=2` −0.455 |
| 鸣牌放宽换爆头（R20 A/B 轮） | 惰性或负 | `bao_claim` −0.006（sb0/m1 档**逐位相同=恒不触发**）；`bao_loose` **−0.296 / −0.346** |
| 手级双计划 + 多巡承诺（R21） | **探针判死** | 设计稿入场（EV 领先 + k 巡承诺）**锁定率 0.0075 局/局**（12/1600，《 0.1 判死线）；换形状门入场（m≥1）后覆盖 22% 局、改写 52% 决策，但 **99.2% 的改写是 sb 不变的并列洗牌**；放宽代价门到 cost≤2 变成「付 +0.221 向听 / 只换 0.6% sb 改善」= `bao_plan` 的失败形态 |
| 「用财神当百搭凑副露」能力缺口 | **不存在** | 吃事件 3402 条含白 **0**；四家重建 190 碰 + 14 杠**全自然**、0 异常（`data/_pm_white_meld_probe.py`） |
| ×4 路线（财飘 / 杠开） | 上界太小 | 可飘点 0；按对手率折算 财飘 **+0.056**、杠开 **+0.015** 分/局 |

**决策层天花板（把独立测量合起来）**：
出牌层同向听可改进点 **1.1%**（teardown D3）+ 鸣牌通道「最多 9 手直接爆头听牌 / 800 局」（`_ob_claim`）
⇒ 所有开关级改动合计最多补 **~10~15% 的 172 手缺口 ≈ +0.03~0.08 分/局**。

> **结论：+0.63 分/局只能靠换「牌型构建」，不能靠任何单步判据。这是本设计稿的前提。**

## 2. 机制假设（可证伪）

**H1（结构假设，主）**：对手的爆头不是"追"出来的，而是**开放手（副露多）+ 保白**的自然产物。
证据：爆头形 = **(4−m) 个自然面子 + 单白**；对手 147 手爆头里 **81.6% 带副露**（≥2 摊 53.1%）、
**53.7% 摸前有 ≥2 张白**；对手胡牌时面子 ≥2 占 **40.2% vs 我 23.3%**；
持白碰转化 **68.2% vs 我 34.9%**；同 (m, 白) 格子里我全面落后（m0k1 我 0% vs 他们 15.9%）。

**H2（前沿假设）**：我在「速度↔番型」前沿上站错了位置 —— 我用**更高的胜率换更小的番**：

| | 我 | 对手（人均） | 读法 |
|---|---|---|---|
| 胡率 | **27.1%** | 24.3% | 我更快 |
| 场均番 | **1.119** | 1.298 | 他们更大 |
| 胡巡 | 8.10 | 8.39 | 我确实更快（速度不是自欺） |

⇒ 平台 payoff 是 **番 × 8（庄位）**，所以正确的动作是**沿前沿往下移**（让出一部分胜率换番型），
而不是"既要速度又要番"（那就是 R20 四轮失败的原因：既没换来番、又丢了速度）。

**H3（轨迹假设）**：分叉在**中期**，不在早期路线也不在末期听型 ——
巡 1 双方 Δ≤1 占比 66% vs 73%（接近），巡 6 起锁死在 **24~36% vs 46~52%**，全程副露差 **1.4~1.7×**，速度全程相同。

**反方假设（必须一起测，防止自己骗自己）**：
- A1：对手只是**牌更好**（发牌运气）—— 已否证：速度相同、进听次数人均相同（1911 : 2019）。
- A2：开放手会**拖慢速度**导致净亏 —— `bao_loose` 的 −0.296 正是这个形态；H2 要求让出的是**受控的**、
  且用机制读数（场均番 / 爆头到达率）证明番真的涨了。
- A3：sim 高估/低估开放手 —— 需要 sim/live 保真度旁证（副露分布、吃摊 ≤2 分布）。

## 3. 方案：三阶段，每阶段都是"能在最便宜的地方失败"

> 设计原则（写死）：**入场判据不得与目标函数同源**（R21 的死因）；**每阶段先看机制读数，再看分**；
> **任一步机制不动 → 就地止损**，不做下一阶段。

### P0 · 值表（不改任何策略代码，1~2 小时）

从 20 房 1600 局**实测**下面这些表（全部按 (m, 白数, 向听, 巡) 交叉，分「我 / 对手」两侧）：

| 表 | 定义 | 用途 |
|---|---|---|
| `T1(m,k)` | 该状态**能走到爆头听牌**的概率（用事件流重建的 tenpai 态判定） | 值函数的核心项 |
| `T2(m,k)` | 到达爆头听牌后**胡掉的概率** | 与 teardown 的转化率对齐（我 83% / 他们 79%） |
| `T3(m,k)` | 该状态的**最终场均番** | 校准 ×2 的实际兑现率 |
| `T4(m)` | 各 m 下的**胡率**（速度代价） | H2 的"让出多少胜率"要按这张表算 |

**P0 的判定（预注册）**：若 `T1(m≥1, k≥1) / T1(0, k)` 的提升 **< 2×**，或 `T4(m)` 的胡率跌幅
**> 3pp/摊**，则 H1 的收益/代价比不成立 ⇒ **就地结案**（连值函数都不用写）。
> 这一条是把 `opp-baotou-teardown.md` §1.1 的**结果表**（赢牌时的爆头率交叉表）升级成**可达性表**；
> 现有表已给方向：m=2,k=2 时对手 78% 的赢牌是爆头、m=1,k=1 时 14%、m=0 时不爆 —— 但那是"条件于赢"，
> 本阶段要的是"条件于状态"。

### P1 · 静态价值函数（最小改动；目标：先让机制动）

把出牌打分从
```
score = s × 100 − ukeire × 0.1 − fan × 5
```
改成
```
score = s × 100 − ukeire × 0.1 − fan × 5 − λ × V̂(手牌, m, 白, 巡)
```
其中 `V̂ = log T1(m,k) + log T3(m,k) − μ × (T4 的速度代价)`，`λ` 是**标定出来的**（不是拍的）：
先在归档的 13064 个决策点上做**离线一致性标定**（选出让 λ 使得被改写的决策点向对手轨迹靠拢、
且不牺牲同向听最优性），再上 A/B。
- **入场是"状态"不是"EV 领先"**：只要 `V̂` 参与打分即可，不存在"计划切换"的门。
- 白被消耗 → `T1 → 0` → 自然惩罚（与 `_draw_quality_bao` 的 99 同构）。
- **不碰**鸣牌硬门（吃 ≤2 / 抓打圈 / 禁杠），**不碰** `chi_prefer_narrow` / `gang_tenpai_only` 这些已晋级项。

臂（全部 `dict(_BG, …)`，同 run 必带 `base_g`）：
`plan_v1`（P1 默认参数）、`plan_v1_low`（λ/2）、`plan_v1_hi`（λ×2）、`plan_v1_noclaim`（只改出牌）、
**阴性对照 `plan_v1_c0`（λ=0，必须逐位等于 `base_g`）**。

### P2 · 手级搜索 / rollout（**只在 P1 把机制推动后才做**）

若 P1 只让机制动了一半（到达率 +<1pp），再升级为**手级搜索**：在"计划分叉点"（m 或白数发生变化的决策点）
枚举 2~3 个候选计划，用 **K 次随机补牌 rollout** 估 `E[payoff]`，其余决策点沿用静态 `V̂`（保证时延）。
- 只在分叉点 rollout（实测每局分叉点数量见 P0 的 `T1` 采样帧数），其余走查表 ⇒ 时延可控。
- **时延红线**：线上出牌窗口 3 s、10 局并发 ⇒ 单次决策 **≤ 100 ms**（比现值高 ≤ 10×）；
  超了就把 K 降到 4 或退回 P1。

### P3 · 真机（只验机制）

按 `docs/HANDOFF.md` §7 跑自由对战；**分数在 800 局尺度判不了**，只看：
①爆头到达率、②场均番、③0 超时/Traceback/409 回归、④chi 对拍 100%、⑤吃摊 ≤2 零违规。

## 4. 预注册判据与止损线（**先写死，再看数**）

| 阶段 | 过线条件（全满足才进下一阶段） | 止损（就地结案） |
|---|---|---|
| **P0** | `T1(m≥1,k≥1) ≥ 2×T1(m=0)` 且 `T4` 每摊胡率跌幅 ≤ 3pp | 任一不满足 → 结案（H1 收益/代价比不成立） |
| **P1**（机制，1000 局/臂） | 爆头听牌**到达率 ≥ 1.9%**（现 0.94%）**或**场均番 **≥ +0.03**，且胡率跌 **≤ 1.5pp** | 机制不动 → 结案，不做 P2 |
| **P2**（机制，1000 局/臂） | 到达率 **≥ 2.4%** 且场均番 **≥ +0.06**，胡率跌 ≤ 2.0pp | 同上 |
| **分数确认**（P1 或 P2 胜出者） | 池化 **Δ ≥ +0.10、z ≥ 2、分半同号**；阴性对照（λ=0）逐位等于 `base_g` | Δ<+0.10 或分半异号 → **归档证否，不重试同形态**（R20 的教训） |

**样本量（按本项目实测的配对 se 算，别拍脑袋）**：

```
需要的局数 n = 1000 × (se_per1000 / 0.05)²        # 判 Δ=+0.10、z=2
实测 se_per1000：bao_plan 0.229｜bao_loose 0.156｜gang_tenpai 0.173｜chi_prefer_narrow 0.163｜d1_suit 0.106
```
- 行为改动型 ⇒ se_per1000 ≈ 0.16~0.23 ⇒ **n ≈ 1.0 万~2.1 万局/臂**（本机 2 臂 10 分片 ≈ 165 s/1000 局 ⇒ **0.5~1 小时/万局**，
  若 P1 只是查表，速度接近基线；P2 有 rollout 会更慢）。
- **机制读数更便宜**（所以先看机制）：场均番 **+0.02 需 ~5000 局**（番 sd=0.365、每局胡率 0.2675）；
  爆头到达率 **+1pp 需 ~7700 局**（p≈0.0094 的十进率）⇒ **1000 局的机制读数只能看方向，不能当判据**，
  所以 P1/P2 的机制门槛要按"到达率 +≥1pp 需 7700 局"来安排采样，或先用**探针级**读数（归档回放，零 A/B 成本）。

## 6. 风险与反模式（把 R20 的教训写死在文档里）

| 风险 | 处置 |
|---|---|
| **再次"用要超越的指标当入场判据"** | 入场 = 状态量（m/白/向听），**不得**要求 `V̂` 领先于旧打分（R21 死因） |
| **同向听内 sb 几乎不可改（1.1%）** | 所以 P1 **不**指望"选哪张"；它的作用是把**轨迹**（m、白存量）推过去 —— 机制读数必须按轨迹量（到达率、场均番）读，**不按翻盘率读** |
| **速度被吃掉** | 以 `T4` 表 + 胡率跌幅 ≤1.5pp 硬闸；跌破就止损 |
| **λ 拍脑袋** | λ 必须由归档标的离线一致性选出来，并做 λ/2、λ×2 剂量档 |
| **选择效应** | 发现集 1000 局只用来筛方向；确认集必须换种子（`seeds_holdout2000`/`holdout2_2000`，都还没被这条轴用过） |
| **确认集不过线还反复试** | 写死：Δ<+0.10 或分半异号 ⇒ 归档证否，不重试同形态 |
| **把"对手更强"当成"我们错了"** | 对手 24.3%/1.298 与我 27.1%/1.119 是**两个不同的前沿点**；P0/P1 只回答"我能不能移到他们那一点"，不回答"谁的分更高" |
