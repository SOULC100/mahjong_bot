## 8. 方法学：本次同时发现的两个「统计口径」问题

### 8.1 `ev["rounds"]` 会丢流局局（**必须用 `blocks`**）

10 场里有 **5 个 batch** 的 `rounds[]` 少条目，合计丢 **6 局，全部是流局**（794/800）；
`blocks` 覆盖 **800/800**。**影响**：任何用 `rounds[]` 统计流局率/总局数的脚本都会**少算流局**
（本复盘早期版本的"0 流局 / 1 流局"就是这么来的，真值是 **11 局**）。
**处理**：新增 `data/_pm_common.py`（权威逐局表），并把
`_pm_rounds / _pm_speed / _pm_convert / _pm_timeouts / _pm_baotou` 全部切到 `blocks` 口径。
核对：`python data/_pm_common.py`。

### 8.2 A/B 臂「与参考基准不同底」⇒ 部分历史 Δ 被高估（详见 `docs/eval-rounds.md` §27）

**触发**：`nodealer`（= `dict(_BG, dealer_policy="off", defend_dealer=False)`）在发现集得 Δ **+0.412（z=2.54）**，
与"`aggr` 为正"的既有结论方向相反。核实结论：

1. **臂构造没问题**：`eval_run.py::build()` 里每个臂都是 `FIELD_CHAMP + CONFIGS[name]`，对手恒为 `FIELD_CHAMP`
   ⇒ 逐 seed 配对永远同底、Δ 有效。问题在 **Δ 归因给谁**。
2. **污染源 ①**：`_BG = {chi_ukeire_gate: True, peng_ukeire_gate: True}`（`eval_run.py:143`），
   而 `FIELD_CHAMP` 里这两个键是 **False** ⇒ `dict(_BG, X)` 臂相对 `base` 多改**两个**开关，
   Δ = **门控常量 + X**。门控常量实测：seeds_1000 **+0.584**、holdout2000 **+0.198**、池化 +0.326
   （**必须按种子集取值**，用池化值减发现集会引入 ≈0.26 的系统偏差）。
3. **污染源 ②**：`eval_report.py --base <X>` 可以不是 `base`。反查每个 run 的 `report_*.txt`（Δ 列显示 `—` 的行）：
   - **ref = `base`**：r1/r2/h1/w1/y1/mx1（其 B 类臂干净）；
     **r14/r15/r16s/r16w/r17/r18/h8~h13/edge/POOL_*/pm_nodealer*/pm_gate_const** ——
     这些 run 的 **A 类臂全部被门控常量污染**；
   - **ref = `both_gate`**：r3–r9/r8b/h2–h5/r11/POOL_r6_h2 ⇒ A 类臂**已经是净效应**，
     但 **B 类臂反而被污染**（例：h4 的 `dealer_off`）。
4. **`nodealer` 的还原**：+0.412（发现集）→ 扣 G 后 **−0.172**；+0.174（确认集）→ **−0.024**。
   ⇒ **+0.41 几乎全是门控常量**，不能用它推翻 `aggr`。
5. **`nodealer` 与 `nodealer_clean` 基因完全相同**：`nodealer` 里的 `defend_dealer=False` 是 **no-op**
   （`FIELD_CHAMP` 本身就是 False）⇒ 两臂的 Δ 应逐 seed 完全相等。
6. **`aggr` 到底值多少**：干净证据只有
   - r1（ref=base，B 类）**−0.272（z=−1.23）** —— 干净但**单次不显著**；
   - h4（ref=**both_gate**，B 类）−0.2975 → 还原后 **−0.100** —— **不是干净复现**；
   - r12（ref=`y_esc_p1`，A 类）**+0.000（z=0.00）** —— YCB 下完全惰性（与 §17 一致）。
   ⇒ 账面"合并 z≈2.1、+0.29 晋级"**不成立**：修正后点估计 **+0.10~+0.27，两次测量彼此不一致且都不显著**。
7. **最强证据是与参考基准无关的「只差一个键」臂对**（同 run 内直接相减）：
   门控的真实边际效应 **+0.11~0.14**（不是账面的 +0.33）；`gang_draw_wall`（残局杠）强场 **恰好 0.000**；
   `gang_tenpai_only` 弱场 **+0.036**（远小于账面的 +0.230）；`chi_prefer_narrow` **+0.167**（同向支持 R15）。
8. **建议**（已写入 §27）：
   - 新臂若写成 `dict(_BG, X)`，**必须**在同一次 run 里带 `base_g = dict(_BG)`，并对 `base_g` 出报告；
   - ledger 增加一列 `ref`（记录该 run 的 `--base`）；
   - 加启动断言：`_BGKEYS <= set(CONFIGS[c]) and "base_g" not in cfg → SystemExit`；
   - 能构成「只差一个键」臂对的，优先用臂对相减。

| `data/_pm_timeouts.py` / `_pm_convert.py` / `_pm_speed.py` / `_pm_baotou.py` | 超时代价 / 转化率 / 速度 / 财神张数 |
