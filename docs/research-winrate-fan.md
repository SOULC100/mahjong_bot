## 1. 现状摘要（读既有文档/数据，不重复测量）

### 1.1 策略现状（`docs/strategy-current.md`）

- 一句话策略：**速度优先**（向听数为纲、进张质量为目），鸣牌是主轴；番型只当"能抵消 1 向听时的加分项"。
- 打分式：`score = 向听×100 − 进张质量×0.1 − 番型×5×庄家倍数 + 杠保留分`；`bound = min_s+1`
  ⇒ **番型最多抵消 1 向听**，且**只在同一个向听层内**参与排序。
- 动作顺序：能胡就胡 → 弃胡打财飘 → 抓打圈受限 → 暗杠（听牌才杠）→ 补杠 → 财飘 → 出牌。
- 鸣牌：明杠（无门控）> 碰（ukeire 门控，`gate_max_shanten=1`）> 吃（ukeire 门控、≤2 摊、多解先消化窄搭子）。

## 3. 候选轴清单（①机制 ②机会频率 ③预期量级 ④实现方案 ⑤决定性实验）

### A. 番型 / 大牌

#### A1. 爆头（×2）路线门控放宽 —— **已实测：有害（结案）**
1. **机制**：`baotou_slack/max_shanten` 把"财神做将、任意摸都胡"的 ×2 路线与标准路线做向听比较；
   放宽到 2 → 更多局面切到爆头世界（该世界里"财神留着做将"，向听按 `shanten_baotou` 计）。
   **副露后并没有被系统性低估**：门控激活的决策点里 **78%（真机）/86%（离线）本来就在副露后**，路线是活的。
2. **机会频率**：真机 s_bao≤2 被门控拦下 **5470 决策点/千局**；离线上限被改写 **1.9 决策/局**。
3. **预期**：+番型、−速度。实测 **场均番 1.160 → 1.190（+0.030）、胜率 26.3% → 22.6%（−3.70pp）、
   Δ分 −0.455（z=−3.47）**。
4. **实现**：`sim/players.py::Smart.__init__` 的 `baotou_slack` / `baotou_max_shanten`（现 1/1）；
   判定在 `mahjong/decision.py::discard_decision` 的 `baotou_route` 分支。
   注意当庄且 `dealer_policy="aggr"` 时被 `dealer_speed` 覆盖成 0/0 ⇒ 该候选只作用于**闲家**。
5. **决定性实验**（已跑，见 §5.4）：
   `python data/_probe_ab_pair.py --run ab1 --cfgfile data/_cfgs_ab1.json --shard K --shards 4`
   → `python data/eval_report.py --run ab1 --field strong --base live`

#### A2. `fan_est="real_ting"`（听牌用真实期望倍率）+ **爆头漏算修复** —— **已实测：噪声（结案）**
1. **机制**：听牌层用 `calc_fan` 逐张试算真实倍率（`log2` 期望翻倍次数）×3 代替启发式 `_fan_value`。
   **旧版有 bug**（`docs/improvement-plan.md` §1：调 `calc_fan` **不传 `baotou`**）→ 真·爆头听牌被算成
   平胡 ×1，B4 的旧证伪结论**不作数**。本轮已修：爆头是"摸牌前 13 张"的性质，与 `_fan_ting_expect`
   拿到的 13 张同源 ⇒ `baotou = any_draw_win(counts, melds)`。
2. **机会频率**：听牌决策点 **8590~9015/千局**（即该轴每一步都在起作用）；但**能改写排序的部分**
   受限于"候选间番型差异"——离线里 fan 项几乎从不成为决定项（见 A3/A4）。
3. **预期**：更准的番型估计 ⇒ 或更敢守爆头、或更少为幻影七对让路。实测 **−0.060 分/局（z=−1.21）、
   −0.30pp 胜率**，场均番 1.154（略降）⇒ **不晋级**（效应低于 1000 局分辨率）。
4. **实现**：`fan_est` 旋钮（`sim/players.py::Smart.__init__` → `mahjong/decision.py::_fan_for`）；
   修复落在 `mahjong/decision.py::_fan_ting_expect`（**已改，默认路径惰性**：`eval_guard` 逐位一致；
   `tests/test_decision.py::test_fan_est_baotou` 已加回归）。
5. **决定性实验**：同上（`configs live_realtung`）。

#### A3. 听口 EV 修正（听口张数 × 番型倍率）—— **有机制、但机会太小（不推荐现在做）**
1. **机制**：听牌层的打分是 `−0.1×听口 − 5×番型` ⇒ 1 个"财神/对子"番型点 = **50 张听口**，
   量纲上明显偏向番型；EV 正确的形式是 `P(胡) × 番型 ∝ 听口 × 2^(fan/3)`（1 次翻倍 = 3 fan）。
2. **机会频率**：真机"选的不是最大听口" **430/千局**，其中牺牲 ≥2 张听口 **280/千局**；
   若改成 EV 口径，**460/千局**决策被改写（离线 73/千局）⇒ **0.07~0.46 决策/局**。
3. **预期**：即便每次都判对，也只有 ~0.1 决策/局 ⇒ **≲0.05 分/局**，低于 1000 局分辨率。
4. **实现**（若要做）：`mahjong/decision.py::discard_decision` 的 `s_map[d]==0` 分支加
   `ting_ev_w`（默认 0 = 旧行为）：`score = s_map[d]*shanten_cost − ting_ev_w*math.log(1+ukeire_val)
   − ting_ev_w*0.231*fan`（0.231 = log2/3）。
5. **决定性实验**：先跑分歧探针确认改写数（本轮已确认太小）→ **结论：不做**。

#### A4. 七对 / 豪华七对（×2/×4）—— **天花板已测死（不做）**
1. **机制**：七对 ×2、豪华 ×4；`shanten()` 已把七对当第二路线取 min，缺的是"承诺"（不鸣牌 / 保留对子）。
2. **机会频率**：真机无副露且对子 ≥5 **540/千局**、≥6 **80/千局**；七对胡占胡牌 4.1%（真机）/5.5%（离线）。
   已有的承诺旋钮 `keep_pairs_min=5`（无副露且对子≥5 时不鸣牌）实测 **+0.024（z=0.37）无效**。
3. **预期**：即便把七对占比翻倍（4.1% → 8%），场均番 **+0.04** ⇒ 按 A1 的兑换率 ≈ +0.6 分/局**上限**，
   但实际只能转化其中一小部分（66% 的胡牌带副露，一旦鸣牌七对即死）⇒ 现实期望 ≈ 0。
4. **实现**（若要做）：`mahjong/decision.py::discard_decision` 同向听内加"保对子分"（`GANG_KEEP_PEN` 同款）
   + `sim/players.py` 的 `keep_pairs_min`（已有）。
5. **决定性实验**：`{"chi_prefer_narrow":true,...,"keep_pairs_min":5}` 1000 局配对（历史已做 ⇒ 无效）。

#### A5. 4 白（×2）—— **无空间**
1. **机制**：手留 4 张财神 ×2（可与爆头叠加）。
2. **机会频率**：真机 **0 次/千局**（100 局里一次没有）；离线决策点 7/千局、4 白胡 2/千局。
3. **预期**：上限 +0.002 场均番 ⇒ **0**。
4. **实现**：无（不值得写代码）。
5. **决定性实验**：无需（频率已归零）。

#### A6. 杠（×2）与速度 —— **已到最优点（并给主 agent 的杠方案频率支撑）**
1. **机制**：每个杠 ×2，且杠本身"不花向听"；暗杠被 `angang_tenpai_only` 限到听牌，明杠/补杠无门控。
2. **机会频率**：暗杠机会 **110~163/千局**（其中 **78~91% 因"打一张仍不听"被拦**）；补杠 **0/千局**；
   明杠机会 190/千局、真机明杠事件 110/千局。"忍掉的杠" = **0.10~0.13 决策/局**。
3. **预期**：R7 已证门控单调为负（墙≤40 −0.021 / 杠后≤1 −0.046 / 杠后听牌 −0.078 / 关明杠 −0.161）；
   R4 的 `angang_all`（暗杠不限听牌）**+0.003 惰性** ⇒ **没有"该忍的杠"空间**。
4. **实现**：主 agent 已加 `gang_tenpai_only` / `gang_draw_wall`（默认关，追加式，未改现有语义）。
5. **决定性实验**：主 agent 的 `gang_tenpai` / `gang_draw28` 方案（弱场已得 +0.51/+0.60；强场窗口见 A7）。

#### A7. 庄家（×8）"做大番" —— **惰性（机制已定位）**
1. **机制**：庄家倍率×8 会把番型项的权重放大 8 倍（`dealer_mult`）。
2. **机会频率**：庄家决策点 **8727/千局**；在这些点上把番型权重 ×8 **只改写 4 个决策（0.0%）**。
   机制：**sim 的候选池不含财神**，而"财神"是启发式番型项里最大的分量（每个 +3）⇒ 它对所有候选

3. 实现：`sim/players.py::Smart.allow_laizi_discard`（已存在，默认关）。

#### B7. 决策时延 —— **算力有余量，但先修缓存**
1. **机制**：线上 3 s 出牌窗口；更多算力本可换更准的估计/更深的搜索。
2. **机会频率**：真机实测 **平均 73 ms、最大 388 ms**（抽样 759 次，**24.8% 的决策 >100 ms**）
   ⇒ 平均 ~40× 余量。**但** sim 单进程内实测**单次决策最长 45.5 s**（4 个分片都出现 43~45 s），
   与 `docs/improvement-plan.md` P0-4 的"`shanten` 无界 `lru_cache`"吻合（内存压力 → 秒级卡顿）。
3. **预期**：一次超时 = 丢一局（≈ −1~10 分），期望值**高于任何剩余番型轴**；反之"多算力换更准"的历史
   证据都是负的（`ukeire_depth` 更慢更差、`wait_full` −0.634、权重旋钮惰性）。
4. **实现**：`mahjong/shanten.py::_best/_mp` 加 `maxsize` 或每局 `cache_clear()`（线上还需注意
   `smart_bot.py` 生命周期）——**这属于可用性修复，建议排在所有策略实验之前**。
5. **决定性实验**：`python -c "<40 决策点计时 + cache_info>"`（见 `docs/improvement-plan.md` §2.3）。

#### B8. 碰的**来源座位**（本轮新轴：摸牌顺序 externality）—— **机制真实但机会太小**
1. **机制**：`碰`会跳过"弃牌者与碰者之间"的玩家的摸牌（碰下家的牌 ⇒ 跳过对家+上家各一次摸牌，
   但让下家马上再摸）。现在的 `should_peng` **完全不知道弃牌者是谁**（`Smart.want_peng` 拿得到
   `game.last_discard_seat` 却没用）。
2. **机会频率**：边际（等向听）碰合计 **504/千局**，其中来自**下家 181/千局**（=0.18 决策/局）。
3. **预期**：即便全部拒掉也只有 ~0.18 决策/局，且方向不确定（拒碰=放弃一次加速）⇒ **≲0.05 分/局**，
   与"收紧鸣牌必为负"的三次历史结论同向 ⇒ **不推荐**。
4. **实现**（若要做）：`sim/players.py::Smart.want_peng` 加 `peng_skip_downstream`（默认 False）：
   当 `(seat - game.last_discard_seat) % 4 == 3` 且 `should_peng(..., ukeire_gate=False)` 为 False 时拒绝。
5. **决定性实验**：`--cfgs "live={...};live_nodown={"peng_skip_downstream":true,...}"` 1000 局配对。

（`wall_lt28_nontenpai` 5 次/100 局）⇒ **在强/混场里它基本没有触发窗口**。
⇒ 建议：**只按赛场实际强度决定是否开**；若赛场大概率是"能打的机器人"，别把它算进预期收益。
